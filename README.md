# 🎓 Student Schedule Management System (Система керування студентським розкладом)

Лабораторна робота № 2 з дисципліни «Конструювання програмного забезпечення» / «Технології розробки ПЗ».  
**Варіант 16:** Система керування студентським розкладом.

## Структура Solution

| Модуль | Роль у команді | Призначення |
|-|-|-|
| `core` | тімлід | загальні інтерфейси, модель заняття, винятки |
| `app` | розробник | реалізація інтерфейсів і консольне меню |
| `tests` | тестувальник | модульні тести JUnit Jupiter |

## Збірка та запуск

Потрібна Java 21. Gradle завантажується автоматично через wrapper.

```powershell
.\gradlew.bat build        # компіляція і тести
.\gradlew.bat :app:run     # запуск консольного застосунку
```

## Робота з гілками

- `dev` — інтеграційна гілка, сюди зливаються Pull Request;
- `feature/<назва>` — гілки завдань, створюються від `dev`;
- `main` — стабільна версія, оновлюється наприкінці кожної віхи з тегом `vX.Y.Z`.
